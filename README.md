# 🗓️ Slot Booking App

A responsive **React + Vite** application that allows users to view and select available time slots (converted from UK time to local time).  
The app also supports week navigation, slot selection, and prevents booking duplicate slots.

---

## 🚀 Features

✅ Responsive layout (works on mobile, tablet, and desktop)  
✅ Weekly navigation with **Next/Previous** buttons  
✅ Real-time UK-to-local time conversion using **Luxon**  
✅ Slot booking and selection state  
✅ Prevents selecting already booked slots  
✅ Smooth scrolling for smaller screens  
✅ Styled with **Tailwind CSS**  
✅ Font Awesome icons for navigation  

---

## 🛠️ Tech Stack

| Technology | Purpose |
|-------------|----------|
| **React (Vite)** | Frontend framework |
| **Tailwind CSS** | Styling |
| **Luxon** | Timezone conversion |
| **Font Awesome** | Icons |
| **JavaScript (ES6+)** | Logic and interactivity |
